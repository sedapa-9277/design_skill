Best Line-up 개인정보처리방침

시행일: 2026년 10월 28일 (최초 2026년 10월 23일)

Best Line-up(이하 "앱")은 동호회 출석 체크와 포지션 배치를 돕는 앱입니다. 앱을 만든 사람은 이용자의 개인정보를 수집하거나 서버로 전송하지 않습니다.

1. 저장하는 정보와 저장 위치

  • 이용자가 직접 입력한 회원 이름, 소속 팀, 부상 여부, 출석 기록, 포지션 배치, 팀 이름
  • 위 정보는 이용자의 휴대폰 안(브라우저 저장소 IndexedDB)에만 저장됩니다.
  • 앱 제작자와 제3자의 서버로 전송되지 않으며, 제작자는 이 정보를 볼 수 없습니다.

2. 수집하지 않는 정보

  • 회원가입, 로그인, 계정 정보 없음
  • 위치, 연락처, 사진, 마이크, 카메라 정보 없음
  • 광고 식별자, 분석(통계) 도구, 광고 SDK 없음

3. 이용자가 직접 내보내는 파일

"백업 파일 저장", "엑셀 내보내기", "명단 복사", "라인업 이미지 저장·공유"를 이용자가 직접 누르면 해당 파일이나 텍스트가 만들어집니다. 이 파일을 카카오톡, 드라이브 등으로 보내는 것은 이용자의 선택이며, 그 이후 보관과 전달은 해당 서비스의 정책을 따릅니다. 백업 파일에는 회원 이름이 암호화 없이 들어 있으니 보관에 유의해 주세요.

4. 외부 서비스

  • 글꼴: 화면 글꼴은 앱과 함께 제공되는 파일을 사용하며, Google 등 외부 글꼴 서버에 요청하지 않습니다.
  • 앱 화면 파일은 GitHub Pages(sedapa-9277.github.io)에서 제공되며, 한 번 받은 뒤에는 폰에 저장되어 오프라인에서도 열립니다.

5. 보관과 삭제

  • 정보는 이용자가 앱 안에서 삭제하거나, 앱 데이터·브라우저 데이터를 지우거나, 앱을 삭제할 때까지 폰에 남습니다.
  • 앱 제작자는 이용자의 정보를 보관하지 않으므로 별도의 삭제 요청 절차가 필요하지 않습니다.
  • 폰을 바꾸거나 데이터를 지우면 기록이 사라집니다. 앱의 "백업 파일 저장"으로 미리 백업해 주세요.

6. 아동의 개인정보

앱은 개인정보를 수집하지 않으며 특정 연령을 대상으로 하지 않습니다.
